# Lumen Duel

Браузерная дуэль на энергоклинках от первого лица. Боёвка в духе Kingdom Come: звезда-трекер на противнике, удары с четырёх сторон, направленный блок, мастерский блок с контрударом, финты, комбо и клинч.

## Запуск

Сборка не нужна. three.js уже лежит в `lib/`, так что игра работает без внешних CDN.

Локально открой `index.html` двойным кликом. Если браузер что-то блокирует, подними простой сервер:

```bash
npx serve .
```

## Деплой на Vercel

1. Залей папку в репозиторий на GitHub.
2. В Vercel нажми Add New, затем Project, выбери репозиторий.
3. Framework Preset: Other. Build Command и Output Directory оставь пустыми.
4. Deploy. Дальше каждый push в main обновляет сайт сам.

| `src/poses.js` | Позы клинка для каждой стороны: стойка, замах, контакт, проводка, блок |
| `src/input.js` | Мышь выбирает сторону на звезде, клавиатура |
| `src/models.js` | Клинок со шлейфом, модель бойца, руки от первого лица |
| `src/view.js` | Камера, рендер, bloom |
| `src/hud.js` | Звезда-трекер, полоски, клинч, надписи |
| `src/world.js` | Арена и небо |
| `src/audio.js` | Синтезированный звук |

Логика (`config`, `utils`, `poses`, `fighter`, `ai`, `game`) не зависит от three.js и запускается в Node, это пригодится для онлайна.

## Как устроен удар

Удар идёт по фазам: замах, контакт, проводка, откат. В момент контакта игра смотрит, что делает защитник:

- держит блок на нужной стороне и поднял его в последние 0,2 с: мастерский блок, атакующий оглушён, у защитника быстрый контрудар ×1,6;
- просто держит блок на нужной стороне: блок стоит выносливости, при нуле защита пробита; вплотную удар может перейти в клинч;
- сам замахивается с той же стороны и вот-вот ударит: клинки сцепляются, начинается клинч;
- в уклонении: промах, атакующий долго восстанавливается;
- иначе попадание: урон, оглушение, замах защитника сбит.

Удар справа прилетает защитнику слева, поэтому звезда показывает угрозу с той стороны экрана, куда надо ставить блок.

## Отладка

В консоли браузера доступен `LUMEN`: `LUMEN.game.fighters`, `LUMEN.game.step(CFG.DT)` и т.д.

## План на онлайн 1 на 1

Боец принимает абстрактный input, поэтому для сети нужен `NetworkController`, который отдаёт input второго игрока. Серверные функции Vercel не держат постоянные соединения, поэтому понадобится WebRTC напрямую между игроками (например, PeerJS) или realtime-сервис вроде PartyKit. Симуляция идёт фиксированным шагом 1/60 с, это основа для rollback-неткода.
